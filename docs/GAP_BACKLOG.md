## Continued work rules

Proceed with local code, synthetic tests and documentation on isolated branches. Preserve existing checkouts and user changes. Bring a concrete proposal/evidence when requesting missing contracts or approval. Public publication/push, deployment, device sideload/QA, new credentials or persistent access, external contact and security bypasses are outside this task's authorization. Keep blockers distinct from ready local engineering work so external authentication decisions do not halt independent reliability improvements.
