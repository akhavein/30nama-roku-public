## Continued work rules

Proceed with local code, synthetic tests and documentation on isolated branches. Preserve existing checkouts and user changes. Bring a concrete proposal/evidence when requesting missing contracts or approval. The user subsequently authorized tested commits to main; the exact private/public destination must be resolved before the first push, and private-only material must not be published. Deployment, device sideload/QA, new credentials or persistent access, external contact and security bypasses remain outside this task's authorization. Keep blockers distinct from ready local engineering work so external authentication decisions do not halt independent reliability improvements.
