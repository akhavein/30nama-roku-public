# Distribution status

This public repository distributes source for an unofficial sideload client. It is not a signed Roku Store package, a Store submission or a certification claim.

A Store publisher must separately establish developer-account access, signing identity, content and brand rights, supported territories, privacy/support documentation, multi-user credential isolation and all applicable certification requirements. A service subscription alone does not establish publishing rights.

Check the current official requirements before preparing an actual submission:

- [Roku publishing guide](https://developer.roku.com/dev/docs/channel-publishing-guide)
- [Certification overview](https://developer.roku.com/dev/docs/certification-overview)
- [Certification criteria](https://developer.roku.com/dev/docs/certification)

Public source availability does not grant access to provider accounts or media. No Store publication is being performed by this repository's initial source push.
